# Tech Studio

منصة عربية تفاعلية لتعلّم تقنية المعلومات وتطوير مواقع الويب (HTML وCSS وJavaScript)، موجّهة لطالبات تخصص تقنية المعلومات.

**المطوّرة:** روابي الكريزي

## المميزات
- دروس متدرجة في HTML وCSS وJavaScript مع تمرين بعد كل درس.
- محرر أكواد مع معاينة مباشرة، وزر لإعادة المثال الأصلي وزر للمسح.
- مشاريع تدريبية بخطوات إنجاز واضحة.
- قسم للأخطاء البرمجية الشائعة.
- حفظ المشاريع على جهاز الطالبة.

## ملفات المشروع
| الملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | التصميم والألوان |
| `app.js` | الدروس والتمارين والمحرر والمنطق |
| `README.md` | هذا الوصف |

## الخصوصية
لا يجمع التطبيق أسماء ولا بريدًا إلكترونيًا ولا بيانات شخصية. المشاريع المحفوظة تبقى في متصفح الطالبة فقط.
عند تفعيل GoatCounter (بوضع الكود في المتغير `GC` داخل `app.js`) تُجمع إحصاءات عامة مجمّعة دون ملفات تعريف ارتباط.

## التشغيل
افتحي `index.html` في المتصفح، أو انشري الملفات على GitHub Pages.
